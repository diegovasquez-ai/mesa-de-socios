# Report template (the Chair's verdict)

Written by the Chair in clear, neutral Spanish. No em dashes. No AI filler: state each point once, no tee-ups ("la clave aquí es", "vamos al grano"). Seat quotes keep their own voice; a verbatim quote stays in English with its source id and a translation in brackets after it. Keep the whole report under about 1,000 words; the round files hold the detail. Reference report (in English, same structure): `sessions/2026-10-09-example-take-the-seed/verdict.md`.

Verdict labels in Spanish: ADELANTE, ADELANTE CON CONDICIONES, REPLANTEAR, ESPERAR, NO LO HAGAS (bands in `scoring.md`).

```markdown

Puntuación por opción: [A] x.x · [B] x.x · [C] x.x · Apoyo a la propuesta x.x/10 · Confianza n/10 · Dispersión n · Votos: [n] respaldan, [n] enmiendan, [n] disienten
```
